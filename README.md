
# 🌐 Decentralized Uptime Monitor

A Web3 SaaS project that monitors website uptime using a decentralized system.  
If a site goes down, users are instantly notified using global node checks.

---

## 🧱 Tech Stack

- Next.js
- Turborepo
- TypeScript
- Clerk (Auth)
- React
- Tailwind CSS

---

## 🚀 Getting Started

1. Clone the repo and install dependencies:

```bash
npx create-turbo@latest
cd my-turborepo
pnpm install
````

2. Run the project:

```bash
pnpm dev
```

---

## 📦 Structure

* `web` – Main frontend app
* `docs` – Documentation app
* `@repo/ui` – Shared UI components
* `@repo/eslint-config` – Linting rules
* `@repo/typescript-config` – Shared TypeScript config
